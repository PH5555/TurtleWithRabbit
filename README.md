## 📖 About The Project

‘별주부전’은 사용자가 바닷속을 여행하는 VR 콘텐츠이다. 사용자는 거북이를 타고 심해 속으로 들어가 여행하면서 아름다운 풍경과 일종의 위기도 마주한다. 바다에 들어가지 않고도 바닷속을 여행할 수 있는 ‘별주부전’은 실제 바닷속과 유사한 공간적, 시각적 체험을 하게 함으로써 현실과 상상의 경계를 자유롭게 드나드는 VR의 특성을 살렸다. 또한 직접 디자인한 여러 바다 생물과 바다 환경을 통하여 아기자기하고 신비로운 바다 속 세계를 체험할 수 있다. 이는 바닷속에 있는듯한 느낌을 주면서도 바다 생물을 실제적이지 않고 귀엽게 디자인하여 리얼한 생물에 공포심을 느낄 수 있는 어린아이들을 포함하여 전 연령의 사람들이 즐길 수 있다. 뿐만 아니라 물에 공포증이 있거나, 바다에 들어가는 것을 꺼리는 사람들도 바닷속에 들어가는 듯한 체험을 할 수 있다.

## 🔶 Scenario1: 거북이를 만나다
